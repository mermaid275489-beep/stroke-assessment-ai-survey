# Toward Objective Stroke Assessment

**Project website:** https://mermaid275489-beep.github.io/stroke-assessment-ai-survey/

Working repository for the methods survey *"Toward Objective Stroke Assessment: An Item-Level Analysis of Clinical Rating Scales for AI-Based Motion Analysis"*.

## Contents

| Path | What it is |
| --- | --- |
| `v5_overleaf_2026-11-21/` | Submission package: `main.tex`, tables, figures, `references.bib`, Supplementary Data 1 |
| `v5/` | Working copy of the final version, including figure sources and revision scripts |
| `ai_literature_supplement/` | AI-evidence literature search: protocol, scripts, screening outputs |
| `ai_gait_factor_restart/` | Tier-1 factor extraction tables |
| `Bridge_matrix_v5_final.xlsx` | Clinical-scale-to-AI-feature bridge matrix |
| `Guideline Summary.xlsx`, `Stroke_Gait_Tools_v5_1.xlsx` | Guideline and assessment-tool summaries |
| `*.ipynb`, `build_*.py`, `generate_*.py` | Literature retrieval notebooks and table-building scripts |

Third-party materials (published articles, clinical guidelines, and assessment-scale forms) are **not** included for copyright reasons.

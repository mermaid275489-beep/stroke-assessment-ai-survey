# Subscription-database imports

Place RIS, NBIB, BibTeX, or CSV exports from Embase, IEEE Xplore, Scopus/Web of Science, or CINAHL in this directory.

Required minimum fields are title, authors, year, abstract when available, DOI or database record ID, database name, and export date. The records must be merged and deduplicated before final screening. Do not overwrite the public-database files.

The current public search is provisional because OpenAlex returned HTTP 429 and no subscription-database exports have been merged.
